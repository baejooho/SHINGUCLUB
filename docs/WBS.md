# SHINGUCLUB — WBS (Work Breakdown Structure) 및 일정

본 프로젝트는 개인 학습/포트폴리오 목적으로 단계적으로 기능을 확장했다.
아래는 구현 완료된 작업을 기능 단위로 정리한 WBS이다.

## 전체 일정 개요

| 단계 | 주요 목표 | 상태 |
|------|-----------|------|
| 1 | Next.js 프로젝트 세팅 및 기본 레이아웃 | 완료 |
| 2 | Firebase 연동 및 로그인/회원가입 | 완료 |
| 3 | 동아리 목록·상세·가입 신청 | 완료 |
| 4 | 회장 승인, 회원/공지/일정 | 완료 |
| 5 | 프로필 및 UI 다듬기 | 완료 |
| 6 | 문서화(README, 요구사항, 아키텍처 등) | 완료 |

## 단계별 세부 WBS

### 1단계 — 기반 세팅
- create-next-app 기반 프로젝트 생성
- 공통 Header, 레이아웃, 글로벌 스타일

### 2단계 — 인증
- Firebase Auth 이메일 로그인/회원가입
- LoginModal, EmailVerifySignupModal
- 로그인 상태에 따른 헤더/접근 제어

### 3단계 — 동아리 핵심
- Firestore `clubs` 목록 조회 및 페이지네이션
- 동아리 상세, 소개 표시
- 가입 신청(`clubApplications`) 및 내 상태 표시

### 4단계 — 운영 기능
- 회장 admin: 신청 승인/거절
- 회원 목록, 공지, 일정(캘린더/날짜별)

### 5단계 — 프로필·UX
- 프로필 조회/수정
- 카드형 UI, 호버 효과 등 프론트 완성도 개선

### 6단계 — 문서화
- README, PLANNING, ARCHITECTURE, ADR, WBS, SETUP 작성
- GitHub에 문서 push

## 일정 관리 방식

기능 단위로 커밋하며, 동아리 목록 → 상세/가입 → 회장 승인 →
부가 메뉴(공지/일정/회원) 순으로 범위를 확장했다.
